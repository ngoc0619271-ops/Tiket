# Tiket Google Form Template

## Form title

Tiket User Feedback — Level 5 on-chain event ticketing

## Questions

1. Name (short answer, required)
2. Email (short answer, required)
3. Wallet address (short answer, required; Stellar public key)
4. Role (multiple choice: Organizer, Buyer)
5. Product rating (linear scale 1–5)
6. What worked well? (paragraph)
7. What was confusing? (paragraph)
8. What should we improve next? (paragraph)
9. Would you use this product again? (yes/no)

- Native Google Sheet response export: <TIKET_GOOGLE_SHEET_URL>

## Network note

The Level 5 cohort uses funded Stellar testnet wallets. The application README advertises a mainnet experience, but [contracts/DEPLOYMENT.md](../contracts/DEPLOYMENT.md) records that the deployed contract and available transaction evidence are testnet-only. Replace the evidence links after a mainnet deployment.
