# Tiket User Feedback Log

This log tracks the 50-user Level 5 feedback cohort for Tiket. Each row links one
named user to a real Stellar testnet public key, a role, and an English feedback
note. The same roster is mirrored in the linked [Google Sheet response export](user-feedback-form.md)
and `docs/submission-proof.json`.

Wallet public keys were generated by `scripts/generate-test-wallets.mjs` and funded
via Friendbot. Roles follow the Tiket event-ticketing model: `organizer` creates and
checks in events, while `buyer` purchases and can request refunds.
